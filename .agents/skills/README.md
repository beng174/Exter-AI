# Licensed marketing references

Reviewed 9 November 2026. These are reference documents for creative analysis,
briefs and testing. AGENTS.md and Exter's three product/UI specs take precedence.
None of these documents is a scoring implementation or validation study. Do not
run their installation, account-mutation, orchestration or embedded example commands.
Never copy source wording into the product or identify sources in user-facing copy.
The existing exter-kernel-task directory is unchanged and is outside this import.

The upload was flattened into numbered filenames, not child folders. Folders were
reconstructed from SKILL.md names and exact upstream Git blob matches, rather than
assuming that filename suffixes identified a skill. Each folder has an unchanged
MIT licence bearing Rebecca Rae Barton's copyright notice.

## Removed and excluded

- **ads-audit, ads-creative and ads-research:** no matching licence/author provenance
  in the uploaded bundle. The other author's MIT licence cannot be assigned to
  them. Their repositories are unverified; they are not used as review sources.
- **Duplicate copies:** wasted-spend-finder and competitor-ads-analyst descriptors,
  examples and references; repeated identical licence files.
- **Orphan Brand Voice & Guidelines example:** no corresponding skill descriptor
  was uploaded. No missing skill was downloaded to reconstruct it.
- **creative-pack.md and dtc-pack.md:** pack lists rather than uploaded skill
  folders; their listed frontend/design/email skills are not imported.
- **env.example and requirements.txt:** execution/configuration helpers, excluded
  from this reference-only import. There were no standalone executable script
  files in the upload; none are retained. Fenced code is documentation only.

References to absent tools, scripts, shared scoring-system.md or other skills
remain historical source text. They do not permit installation, network/provider
calls, parallel agent tasks or changes to Exter. The external account-audit score,
taxonomies, metric definitions and thresholds do not replace Exter's own rules.
Several numeric claims contradict each other and have no cited empirical study.
See [the creative rules review](../../research/CREATIVE-RULES-REVIEW.md) for the
rule-by-rule assessment and validation-only proposals.
