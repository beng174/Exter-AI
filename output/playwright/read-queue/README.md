# Slow index refresh regression

Chromium at 1440px using fictional API responses from the disposable 20,000-ad
fixture. Both Creatives and Home receive a 6.5-second second refresh, followed by
a transient busy response and successful recovery. Reads never overlap or abort;
previously loaded content stays visible with a refresh warning. No external calls
or writes are allowed. results.json records the measurements.

Run a local Vite preview, then `python3 tests/ui_index_poll_browser.py`. The fixture
JSON is generated by the infrastructure suite with INDEX_FIXTURE_OUTPUT set to
`/tmp/exter-index-browser-fixture.json`. These are fixtures, not live verification.
