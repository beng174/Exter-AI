# Sample regression evidence

`tests/ui_sample_browser.py` checks all 15 screens at 1280, 1440 and 1920px,
five mobile views, the sidebar, sample isolation, read-only actions, source links,
canned Ask answers and private metric boundaries. It blocks external browser
requests and runs against the local in-memory fixture API. No provider calls.
Fixtures are not live verification. Each comparison PNG places the explicit
fictional sample workspace beside its approved illustrative reference.

Primary categories are read-only here. Comparison tables use matching media groups;
rich sample account results and non-comparison sections remain populated. Scores
are illustrative sample scores, not a production Working Score implementation.
