## Precedence and conflict decisions

| Disagreement | Chosen rule and reason |
| --- | --- |
| User brief/accuracy versus source assumptions | Brand brief and research/ACCURACY-SPEC.md win; then supplied scraper guidance, then remaining research. |
| Sum-based, view-based or ambiguously parenthesised engagement | Owner's median((likes+comments)/followers), latest 12 official posts. Never mix denominators. |
| Micro ends at 50k; other templates call 100k macro | Owner tiers: nano <10k, micro [10k,100k), mid [100k,500k), macro >=500k. |
| Older product flow requires >40k followers | New discovery uses the brief's range and all four requested tiers. |
| Scraped public counts called measured | Discovery only; displayed official counts require Graph verification, otherwise Unverified. |
| Rough 1–3% healthy engagement versus cohort medians | No compatible UK median supplied. Tier rates in the reference are disclosed starting assumptions, not empirical benchmarks. |
| Multiple STAR / commercial / community / content scores | One Exter six-component fit checklist, separate from ad Creative/Working Score; no imported veto runtime. Versioned weights are provisional, not outcome claims. |
| No numeric score without full coverage versus requested fit breakdown | Show assessed points/coverage and Provisional; no free points for missing checks. Client gate still closed. |
| Opaque-only handles/transient profile links | Owner requires saved searchable handles, deduplication, deletion and cards. Store minimal public profile fields with access/retention controls, never raw contact dumps. |
| No invented global freshness period | Owner requests monthly refresh. Use calendar-month due dates, preserve original success dates after failure. |
| Broad audience demographics and fake-follower percentages | Public profile signals cannot establish audience demographics or fraud. Show specific estimated risk flags; missing audit is not a pass. |
| UK geography inferred from weak hints | Explicit base plus supporting reasons; domain/spelling alone cannot pass UK shortlist. Creator base is not audience location. |
| Platform tagging treated as a partnership | Require disclosure plus a named brand; ordinary tags remain mentions. Ad appearance needs direct stored proof. |
| CLI, preference bypass and only quote costs above $5 | Server-side existing client; quote and reserve every paid run. Existing GBP budget always wins. No paid auto-retries. |
| New contact waterfalls, outreach cadences, contracts, memory registries | Out of scope. This task authorises discovery, not contact or content use. No upstream scripts, registries or chained skill actions. |
| FTC-only guidance | UK GDPR, PECR and ASA/CAP guidance for UK work. Public business email is not consent to market. |
| Fresh account warming and paid comment tactics | Excluded. No engagement manipulation or account automation. |
| Claimed ROI, ideal creator mixes and single-vendor case metrics | Omitted: not comparable evidence for UK Instagram discovery. |
| Generic trend ideas versus current trend claims | Suggested queries only until dated geography/window measurements exist. |
| Various accuracy gates | Creator good-fit and UK precision >=85%, separately, with real owner labels; fixtures never open gates. Other accuracy gates unchanged. |
