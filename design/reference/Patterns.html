What each action means

Test now
When: it wins often in the category and you use it 15+ points less.
Exter suggests: a brief with 3 variants, linked to the ads that prove it.
Scale
When: your own winners sit where competitors barely go.
Exter suggests: more versions of the winning concept and new creators.
Fix
When: you use it a lot but win less than the category.
Exter suggests: new hooks or formats for the same idea.
Reduce
When: it wins rarely everywhere and you overuse it.
Exter suggests: move budget to Test now items.
Watch
When: a competitor idea is new or rising this week.
Exter suggests: a note in the report; test if it is still rising next week.
